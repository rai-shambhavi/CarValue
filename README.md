# 🚗 CarValue
Used-car price prediction &amp; depreciation analyzer

### 1. Project Overview
Buying or selling a used car can be challenging because vehicle prices vary depending on several factors, including brand, age, mileage, and condition.
CarValue aims to explore these factors through data cleaning, exploratory data analysis (EDA), and interactive visualizations to better understand used-car pricing patterns.

### 2. Objectives
Analyze used-car selling prices across different brands.
Identify the relationship between vehicle age and selling price.
Investigate how kilometers driven relate to vehicle prices.
Explore price distributions and variations across vehicle categories.
Create interactive visualizations to communicate insights effectively.

### 3. Key Features
Brand-wise Price Analysis: Compare median selling prices among the most frequently listed brands.
Vehicle Age Analysis: Examine how selling prices change with vehicle age using median prices and interquartile ranges.
Mileage Analysis: Explore the relationship between kilometers driven and selling price.
Interactive Visualizations: Use Plotly to create interactive charts with hover details.
Data-Driven Insights: Identify trends and patterns in used-car listings.

### 4. Tech Stack
- Python: Data analysis and scripting
- Pandas:	Data manipulation and cleaning
- NumPy:	Numerical operations
- Plotly Express:	Interactive visualizations
- Plotly Graph Objects:	Custom charts
- Jupyter Noteboo:k	Exploratory analysis and experimentation
